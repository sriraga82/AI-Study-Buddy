# 🎓 AI Study Buddy

AI Study Buddy is an interactive learning assistant developed using Python and Streamlit. It helps students understand academic concepts and improve their study habits.

## Features

### 1. Ask a Question
- Enter academic questions.
- Get explanations for topics such as Python, OOP, DBMS, SQL and Machine Learning.
- Receive instant responses.

### 2. Study Tips
- Enter a subject or topic.
- Get six practical study suggestions.
- Improve revision and learning habits.

## Technologies Used
- Python
- Streamlit

## Installation

1. Clone the repository:

```bash
git clone https://github.com/sriraga82/AI-Study-Buddy.git
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run app.py
```
